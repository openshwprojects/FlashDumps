# TuyaMCU OTA firmware catalogue

This collection contains firmware offered by Tuya as channel 9 (TuyaMCU) updates. These files are for the secondary MCU in a TuyaMCU product, not for its Wi-Fi module.

The product key identifies the Tuya product for which the OTA was offered. The listed version is the target OTA version; a current version used to reveal an update is not evidence that the version ever shipped in a retail device.

The catalogue currently contains 145 unique OTA payloads. Release-note text for 140 entries comes directly from cached Tuya channel-9 JSON; 3 superseded entries use text from their matching Tuya update screenshots; and 2 responses had no description. Original Tuya CDN URLs were captured for 142 payloads and may stop working independently of the archived files.

Filenames include the product identification and, where supported by direct evidence, an MCU identification. Changelog wording is retained from Tuya. Matching update screenshots, where available, are in [`images/`](images/).
