# BroadLink OTA firmware

Firmware packages for BroadLink devices and OEM products, including RM4, RM Mini, RM Pro, smart plugs, bulbs, gateways and air conditioners. The collection contains 250 distinct binaries; identical downloads are stored once. Original download and archive-member filenames are preserved. Device-type and archive subfolders distinguish different files that share a filename.

The table lists intended products, platforms, device-type IDs, firmware versions and original download URLs. Device-type IDs are decimal. A chipset or product-family match alone does not establish firmware compatibility. Some filenames identify device types rather than versions; unrecorded versions are left explicit.

Platform identification uses embedded SDK and product strings where available. MediaTek MT7681 images contain MT7681 calibration, compiler or updater-path identifiers. MT7687 images contain MT7687 SDK identifiers. The AUX MT7682 targets contain `AUX-42037-7682-BL-1825` and `AUX-47019-7682-BL-JD-AUX-WX-HI-2579` build strings and shared MT7686 SDK driver paths. Marvell images contain WMSDK and product/updater identifiers; 88MC200 and 88W8801 are named only where those targets are indicated. RTL8710/RTL8720 family labels follow the vendor package names.

The RM MAX packages name an 8720 target and contain AmebaZII / RTL8710C SDK identifiers. AC Freedom air-conditioner packages for device types 25119, 25157, 25280 and 43715 contain either RTL8195A or AmebaZII / RTL8710C SDK identifiers. The eHub image contains a MediaTek MT7628 device tree (`broadlink,dnakit-mt7628nn-board`), DNAKit/LEDE 17.01.4 metadata and a kernel with valid uImage header/data CRCs. BestCon IHG gateway offerings cover several hardware revisions: hardware 51 catalogue notes name MT7628 builds, hardware 54 tar packages contain an MT7621-specific SDK library, and hardware 65 packages embed `MT7621W`. The exact SoC is left unconfirmed for the opaque hardware 62, 63, 64 and 66 packages. Magic Home and Smart Garage also supply ZIP OTA bundles whose member filenames identify a BroadLink `0920` target; the MCU behind that target remains unconfirmed. Magic Home additionally supplies integrity-valid AmebaZII / RTL8710C gateway packages. The SP mini `0907` packages contain `SPMINI-41027-0907-BL-1980`, `SPMINI-41034-0907-BL-FC-1187`, `SPMINI-41035-0907-BL-FC-1208`, `bl0907` and `ssv6060p/drv_uart.c` / `ssv6060p/irq.c`, identifying the BroadLink 0907 target as the iComm SSV6060P platform.

`10019.bin` belongs to the SP mini 2 device-type directory (10024), whose metadata names that product family. Its opaque payload does not establish a chipset.

The RTL8710, RDA5981, RM MAX and MT7682 MMM containers pass header/payload SHA-1 and LZMA decompression checks. Other package formats have not been fully checked. Files are provided for archival and analysis; exact hardware and firmware compatibility must be established before use.

Original server URLs are listed below. For files obtained inside archives, the archive URL and exact member name are shown instead of an inferred standalone download URL. URLs may no longer be available. Firmware offering versions can differ from filename numbers; the RM Mini 44054 offering, for example, links to `44055.bin`.

Public release lists vary by app and region. Examples: [BroadLink Europe](https://app-service-deu-6dc239d5.ibroadlink.com/getfwversion?devicetype=44939), [BroadLink USA](https://app-service-usa-21b17cc3.ibroadlink.com/getfwversion?devicetype=44939), [BroadLink Singapore](https://app-service-sgp-f51f7f9c.ibroadlink.com/getfwversion?devicetype=25678), [BroadLink China](https://app-service-chn-467a8f05.ibroadlink.com/getfwversion?devicetype=25747), [BG type 20963](https://app-service-deu-cea0797d.ibroadlink.com/getfwversion?devicetype=20963), [BG type 20962](https://app-service-deu-cea0797d.ibroadlink.com/getfwversion?devicetype=20962) and [AC Freedom China type 43715](https://app-service-chn-31a93883.ibroadlink.com/getfwversion?devicetype=43715). The release lists and linked package downloads are available without account credentials. Device names are cross-referenced with the [python-broadlink supported-device table](https://github.com/mjg59/python-broadlink/blob/master/broadlink/__init__.py); a shared offering does not imply identical hardware. Byte-identical offerings at alternate URLs link to the single cached file.

Twenty-three downloadable RDA5981 packages cover BG sockets/adaptors, SP4 plugs, smart bulbs and S3 hubs. Application versions are recovered from compiled firmware version functions; catalogue version `0` is a placeholder. Empty server filename headers use the original URL basename without an added extension. `SMARTSOCKET-46053-5981-BL-FC-2704.upd.bin` is offered as 46053 but contains application 57053 / SVN 2704. Its catalogue `hash512` does not match the served bytes or the inner MMM/payload forms; repeated downloads are identical and the embedded MMM SHA-1 checks pass.
