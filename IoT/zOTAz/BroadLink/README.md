# BroadLink OTA firmware

Firmware packages for BroadLink devices and OEM products, including RM4, RM Mini, RM Pro, smart plugs and air conditioners. The collection contains 129 distinct binaries; identical downloads are stored once. Original download and archive-member filenames are preserved. Device-type and archive subfolders distinguish different files that share a filename.

The table lists intended products, platforms, device-type IDs, firmware versions and original download URLs. Device-type IDs are decimal. A chipset or product-family match alone does not establish firmware compatibility. Some filenames identify device types rather than versions; unrecorded versions are left explicit.

Platform identification uses embedded SDK and product strings where available. MediaTek MT7681 images contain MT7681 calibration, compiler or updater-path identifiers. MT7687 images contain MT7687 SDK identifiers. The AUX MT7682 targets contain `AUX-42037-7682-BL-1825` and `AUX-47019-7682-BL-JD-AUX-WX-HI-2579` build strings and shared MT7686 SDK driver paths. Marvell images contain WMSDK and product/updater identifiers; 88MC200 and 88W8801 are named only where those targets are indicated. RTL8710/RTL8720 family labels follow the vendor package names.

`10019.bin` belongs to the SP mini 2 device-type directory (10024), whose metadata names that product family. Its opaque payload does not establish a chipset.

The RTL8710, RDA5981 and MT7682 MMM containers pass header/payload SHA-1 and LZMA decompression checks. Other package formats have not been fully checked. Files are provided for archival and analysis; exact hardware and firmware compatibility must be established before use.

Original server URLs are listed below. For files obtained inside archives, the archive URL and exact member name are shown instead of an inferred standalone download URL. URLs may no longer be available. Firmware offering versions can differ from filename numbers; the RM Mini 44054 offering, for example, links to `44055.bin`.

Public release lists: [BG type 20963](https://app-service-deu-cea0797d.ibroadlink.com/getfwversion?devicetype=20963) and [BG type 20962](https://app-service-deu-cea0797d.ibroadlink.com/getfwversion?devicetype=20962). The release lists and linked package downloads were retrieved without account credentials. Byte-identical offerings at alternate URLs link to the single cached file.

Eight downloadable RDA5981 packages are listed for BG device types 20962 and 20963. Seven of these downloads have an empty server filename header, so their original URL basenames are retained without adding an extension. Their application versions come from compiled firmware version functions; catalogue version `0` is a placeholder. `SMARTSOCKET-46053-5981-BL-FC-2704.upd.bin` is offered as 46053 but contains application 57053 / SVN 2704. Its catalogue `hash512` does not match the served bytes or the inner MMM/payload forms; repeated downloads are identical and the embedded MMM SHA-1 checks pass.
