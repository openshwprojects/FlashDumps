# BroadLink OTA firmware

Firmware packages for BroadLink devices and OEM products, including RM4, RM Mini, RM Pro, smart plugs and air conditioners. The collection contains 119 distinct binaries; identical downloads are stored once. Original download and archive-member filenames are preserved. Device-type and archive subfolders distinguish different files that share a filename.

The table lists intended products, platforms, device-type IDs, firmware versions and original download URLs. Device-type IDs are decimal. A chipset or product-family match alone does not establish firmware compatibility. Some filenames identify device types rather than versions; unrecorded versions are left explicit.

Platform identification uses embedded SDK and product strings where available. MediaTek MT7681 images contain MT7681 calibration, compiler or updater-path identifiers. MT7687 images contain MT7687 SDK identifiers. Marvell images contain WMSDK and product/updater identifiers; 88MC200 and 88W8801 are named only where those targets are indicated. RTL8710/RTL8720 family labels follow the vendor package names.

`10019.bin` belongs to the SP mini 2 device-type directory (10024), whose metadata names that product family. Its opaque payload does not establish a chipset. The RDA5981 SP4L-UK and BG Electrical files are embedded MMM upgrade containers extracted from their full flash images at offset `0x90000`. Each decompresses to the installed application at `0x9000` byte-for-byte. Their descriptive extraction filenames are not original server filenames, and no download URL is established for either. Installed versions/SVN revisions are identified from the firmware project-info functions.

The RTL8710 and RDA5981 MMM containers pass header/payload SHA-1 and LZMA decompression checks. Other package formats have not been fully checked. Files are provided for archival and analysis; exact hardware and firmware compatibility must be established before use.

Original server URLs are listed below. For files obtained inside archives, the archive URL and exact member name are shown instead of an inferred standalone download URL. URLs may no longer be available. Firmware offering versions can differ from filename numbers; the RM Mini 44054 offering, for example, links to `44055.bin`.
